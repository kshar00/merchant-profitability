# Data dictionary

All data is synthetic, generated by `src/generate_data.py` (seed 20251231). Amounts are in EUR.

## merchants.csv — one row per merchant

| Column | Meaning |
|---|---|
| merchant_id | `M0001` … `M0550` |
| segment | Enterprise retail, Marketplaces, Travel & hospitality, Digital subscriptions, SMB retail |
| country | Merchant's home country: NL, DE, UK, FR, ES, Nordics, US |
| pricing_model | `ic_plus` (interchange++) or `blended` |
| start_month | First month the merchant processes (merchants that join mid-period ramp up over a few months) |
| end_month | First month with no processing, for merchants that leave; empty otherwise |
| cost_to_serve_eur_month | Allocated account management and support cost per active month |

## pricing.csv — contract terms, one row per merchant, payment method and price period

| Column | Meaning |
|---|---|
| merchant_id, payment_method | Keys |
| valid_from, valid_to | Price applies to months where `valid_from <= month < valid_to`; `9999-12-01` = open-ended |
| pct_fee | Interchange++: markup on TPV. Blended: the all-in percentage. BNPL: the BNPL price |
| fixed_fee_eur | Fee per transaction |
| passes_through_interchange | 1 = interchange and scheme fees are billed to the merchant at cost (interchange++ cards and wallets) |

A renewal at a new price ends the old row and starts a new one in the same month.

## payment_method_costs.csv — cost assumptions per payment method

| Column | Meaning |
|---|---|
| interchange_scheme_pct_domestic | Interchange + scheme fees as % of domestic TPV |
| interchange_scheme_pct_cross_border | The same for cross-border TPV |
| scheme_fee_fixed_eur | Fixed scheme fee per transaction (local bank payments) |
| partner_fee_pct | BNPL provider fee as % of TPV |
| processing_cost_per_txn_eur | Own processing cost per transaction |
| carries_loss | 1 = fraud and chargeback losses can occur (cards and wallets) |

## monthly_transactions.csv — merchant × month × payment method

| Column | Meaning |
|---|---|
| merchant_id, month, payment_method | Keys (month = first day of the month) |
| transactions | Number of payments |
| tpv_eur | Total payment volume |
| cross_border_tpv_eur | Part of TPV paid with cards issued outside the merchant's country |
| fraud_chargeback_loss_eur | Losses from fraud and chargebacks that the business bears |

## Views built by sql/00_economics_model.sql

- `fact_economics`: the transaction rows priced, with gross revenue, pass-through costs, net revenue, processing cost and losses.
- `merchant_month`: one row per merchant and month, adding cost to serve and contribution 1 and 2.
